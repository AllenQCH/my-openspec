# 后端设计规范

- 技术基线为 Java 8、Spring Boot、Maven 和多仓库服务架构。
- 设计前必须追踪真实入口、跨服务调用、数据库动作、状态分支和外部依赖，并将 GitDiagram/code_graph 写入实际改动服务的 OpenSpec。
- 公共 DTO 和接口变更必须保持既有消费者兼容，明确依赖包发布及下游构建顺序。
- `hsp-invoice` 是 Maven 依赖仓库，使用实际消费版本对应的既有维护分支；不得使用蓝鲸需求分支。
- 可部署服务使用 `feature/<蓝鲸需求号>-<蓝鲸需求中文标题>`，默认基于最新 `origin/master`。
- 设计必须包含并发一致性、幂等、回滚、灰度和旧调用方兼容性分析。
